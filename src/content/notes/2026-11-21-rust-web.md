# RustでWebApplicationを作る

つまずいた部分のメモ

- WebAssemblyターゲット`wasm32-unknown-unknown`のドキュメント上では、C/C++に相当するものがないため他をおすすめする旨の記載[^1]があり否定的に見えるが利用可能か？<br>→`wasm32-unknown-unknown`は特定のOSや実行環境に依存しないターゲットのため、例えば`std::fs`によるファイル操作は機能しない。<br>今回はブラウザ上のエディタ作成のため問題ない

[^1]: https://doc.rust-lang.org/stable/rustc/platform-support/wasm32-unknown-unknown.html

- `Result<(), JsValue>`は何を意味する？<br>→Result自信は列挙型。その中の()はユニット型。処理の成功と失敗を表現する。`Result<Ok(T), Err(E)>`<br>ここでの`()`は、成功時に返す具体的なデータないことを表す(処理が終わったことだけを伝える)

- `.ok_or_else()`はどういう振る舞いか？<br>→標準ライブラリのOption型のメソッド。Option<T>は値が存在する場合(Some)と存在しない場合(None)を表す。<br>今回はwindow()の戻り値に対して呼び出しているため、SomeはOkに変換され、NoneはErrとなる

- はてなとセミコロンがあるとどうなる？<br>

`body.append_child(&heading)?;`の場合<br>
1. `append_child()`を実行する
2. `?`で成功・失敗を確認する
3. 成功した場合は結果を取り出す
4. `;`で文を終了し、取り出した結果は使わない
※Rustでは構文の最後の値を返すが、値がない場合は`;`で明示的に終了する。C言語の`;`とは意味が異なる
